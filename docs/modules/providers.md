# `providers`

`providers` holds Aircall, Apollo, Attio, Breakcold, Exa, Fathom, Firecrawl, Fireflies, GitHub, Google, Granola,
HubSpot, Lusha, Microsoft, Notion, Slack and Unipile definitions. Pass an entry
such as `hubspot` to OAuth or HTTP calls. Provider modules own scopes; workspace-specific base URLs remain app configuration.
