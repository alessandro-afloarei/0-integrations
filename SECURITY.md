# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting: open the repository's **Security**
tab and choose **Report a vulnerability**. Never report one in a public issue, a pull request or a discussion.

Include the affected module and version, what an attacker can do, and the steps to reproduce it. Leave out real
tokens, keys and anyone's personal data.

## Supported versions

| Version | Supported |
|---|---|
| The latest minor release | Yes |
| Every earlier release | No |

A fix ships in a new release of the latest minor line. Upgrade to it to get the fix.

## What happens next

We aim to answer every report within 7 days. We then agree with you on a fix and a disclosure date, and credit you in
the release notes unless you prefer otherwise.
